✨ 도형코스

📂 보관함

마음에 드는 도형 코스나 직접 그린 코스에 이름을 붙여 별도 저장해 두고, 언제든 다시 불러와 걸을 수 있는 나만의 코스 금고입니다.

📖 설명서

현재 보고 계신 상세 사용설명서 창을 언제든 다시 열어 각 메뉴와 버튼의 기능을 확인할 수 있습니다.

3️⃣ 도형 스튜디오 & 도안 비교·검증 메뉴
🐾 카테고리 탭 & SVG 프리뷰

도형 스튜디오에서 [전체 30 / 동물 15 / 자연·꽃 5 / 심볼·탈것 10] 탭으로 분류해 볼 수 있으며, 상단 프리뷰 창에서 원본 실루엣과 출발점(하늘색 점)을 즉시 확인합니다.

📏 목표 외곽 둘레 슬라이더

1.0km(가벼운 산책)부터 10.0km(장거리 러닝)까지 0.5km 단위로 코스 크기를 조절하며, 예상 소요 시간(분)이 자동 계산됩니다.

💾 코스 저장 (상단 서브바)

방금 생성된 코스가 마음에 들 때 누르면 즉시 보관함 저장 창이 열려 이름을 지정해 영구 보관할 수 있습니다.

🔄 길 재매칭

지도를 드래그하여 다른 동네나 공원으로 이동한 뒤 누르면, 이동한 화면 중심의 실제 길에 맞춰 현재 도형 코스를 즉시 다시 그려줍니다.

🔍 도안 비교 (검증 패널)

실제 길로 변환된 코스가 원래 의도한 도형과 잘 맞는지 비교·조정하는 핵심 메뉴입니다.
• 실제 보행길만: 원본 도안을 숨기고 실제 걸어야 할 도로 코스만 표시
• 1:1 겹쳐 비교: 실제 도로 코스와 반투명 원본 도안을 겹쳐 일치도 검증
• 원본 도안만: 도로 매칭 전 순수 도형 외곽선만 단독 표시
• 원본 도안 투명도 (5%~95%): 겹쳐진 원본 그림의 진하기 조절
• 도안 회전 각도 (0°~360°): 동네 골목길 방향에 맞춰 도형을 15° 단위로 회전시켜 도로 일치도를 높임

📍 불러오기 & 🗑️ 삭제

저장된 목록에서 [📍 불러오기]를 누르면 언제든 해당 코스로 지도가 즉시 이동·복원되며, [🗑️] 버튼으로 불필요한 코스를 삭제합니다.

5️⃣ 우측 플로팅 버튼 & 지도만 보기 미니 바
🗺️ 지도만 보기 / ⚙️ 메뉴 보이기

상·하단 메뉴창이 지도를 가리지 않도록 숨기거나 다시 펼칩니다. 메뉴를 숨기면 상단에 초소형 미니 바(코스명 | 이동거리 | 🚶 시작 | 📂 보관함 | 📖 설명서 | ⚙️ 설정 펼치기)만 남습니다.

▶️ 시뮬레이션 / ⏹️ 정지

실제로 나가서 걷기 전에 🚩 출발·도착점부터 코스 끝까지 그려진 도안의 모든 정점을 100% 오차 없이 똑같이 따라가며 완주 경로와 거리를 가상으로 미리 걸어보는 기능입니다.

📥 GPX

생성된 가이드 코스나 내가 실제로 걸은 GPS 궤적을 표준 .gpx 파일로 다운로드하여 스마트워치(가민·애플·갤럭시워치)나 러닝 앱(Strava 등)에서 사용할 수 있습니다.

📍 내 위치

현재 스마트폰·PC의 GPS 위치로 지도 중심을 즉시 이동시키고 파란색 펄스 마커로 내 위치를 표시합니다.
